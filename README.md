# 股票判断机 v12

独立于旧版 `stock-judge-app` 的新工作仓库。

本版重点：
- 首页只展示股票与搜索框。
- 底部整页菜单固定为：类型、结论、点评、收藏、设置。
- 类型和结论从数据动态生成；新增数据类型会自动出现。
- 详情里可切换并保存：结论、每条判断结果、每条性质；本地修改不会被后台更新覆盖。
- 公告列表固定放在详情最下面，按时间最新在上，并显示公告类型标签。
- 公司概况内嵌同花顺页面，股票代码自动替换；内嵌区域允许横向滚动。
- 数据源与激活码分开保存；“解密密钥”在界面统一改称“激活码”。
- 支持收藏/点评/手动修改备份恢复、加密 TXT 导入、系统返回键、IndexedDB 缓存。
- 设置里提供“检查 App 更新”入口。

## 激活码
本版不把激活码写入源码。首次安装后进入“设置 → 激活码”，填写后再更新数据。

## 数据源
默认读取旧数据仓库的加密 stocks.txt，也可以在“设置 → 数据源”替换为新的数据地址；两者互不影响。

## 构建
GitHub Actions → Build APK。当前构建不强制要求 GitHub Secret 的 AES_KEY，因为激活码由 App 内单独输入。
